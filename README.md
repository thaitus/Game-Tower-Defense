# 🛡️ Guardian Defense

Một game **Tower Defense kết hợp Hero** được xây dựng bằng **Flutter + Flame**, nơi người chơi triệu hồi Guardian để ngăn chặn quái vật tràn ra từ các Cổng Đỏ bí ẩn.

---

## 🎯 Mục Tiêu Dự Án
- Xây dựng game mobile 2D bằng Flutter + Flame
- Gameplay ổn định – rõ ràng – dễ tiếp cận
- Có hệ thống Guardian riêng
- Có tài liệu rõ ràng phục vụ học thuật

---

## ⚔️ Gameplay Ngắn Gọn
- Thể loại: Tower Defense
- Người chơi đặt Guardian để chặn quái
- Enemy đi theo đường cố định
- Thắng → bảo vệ thành công
- Thua → quá nhiều quái lọt qua
